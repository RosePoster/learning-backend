# 225. 用队列实现栈

## 我的思考

这题只能接受两种复杂度分配：

1. 每次 `push` 为 O(n)，`pop/top` 为 O(1)；
2. 每次 `pop` 为 O(n)，`push` 为 O(1)。

## 卡点

原以为可以像 stack 模拟 queue 一样，通过一次转移元素实现摊还 O(1)，即每个元素只入栈两次、出栈两次。

但队列模拟栈时，LIFO 顺序和 FIFO 顺序天然相反，必须在 `push` 或 `pop` 的某一侧付出 O(n) 的调整成本。

## 关键点

## 复杂度

单队列 `push` 旋转方案：

- 时间：
  - `push`: O(n)
  - `pop`: O(1)
  - `top`: O(1)
  - `empty`: O(1)
- 空间：O(n)

双队列延迟转移方案：

- 时间：
  - `push`: O(1)
  - `pop`: O(n)
  - `top`: O(n) 或通过额外变量优化为 O(1)
  - `empty`: O(1)
- 空间：O(n)

## 注意

这题和“用栈实现队列”不同。

用栈实现队列可以通过输入栈和输出栈，把元素一次性转移到输出栈，实现摊还 O(1)。  
但用队列实现栈时，队列没有反向弹出的能力，无法通过一次转移长期维持 LIFO 顺序，因此必须在每次 `push` 或每次 `pop` 时进行 O(n) 调整。

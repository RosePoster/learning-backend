# 273. Integer to English Words

## 我的思考

将整数按每三位一组拆分，因为英文大数单位按照 `Thousand / Million / Billion` 每三级提升一次。

对每个小于 1000 的 section，分别处理：

- 百位；
- 十位；
- 个位；
- `10 ~ 19` 作为特殊映射直接查表。

主循环通过 `num % 1000` 从低位到高位依次取出 section，并记录对应的量词级别。由于解析顺序与最终输出顺序相反，先将各 section 保存到数组，再从高位到低位统一拼接。

## 卡点

耗时 40min。

主要时间花在：

- 映射表结构的选择与录入；
- 最初使用 HashMap，后来发现连续整数查表使用数组更合适；
- 处理低位到高位解析、但需要高位到低位输出的顺序问题。

## 关键点

每个三位 section 可以独立转换成英文，再追加对应的量词。

值为 0 的 section 直接跳过，避免输出多余量词。

## 复杂度

时间复杂度：`O(log num)`，对 `int` 范围可视为 `O(1)`。

空间复杂度：`O(1)`。

## 注意

连续整数到固定字符串的映射优先使用数组，不需要 HashMap。

解析顺序与输出顺序相反时，先保存分段结果，再逆序拼接，比在头部不断插入更清晰。

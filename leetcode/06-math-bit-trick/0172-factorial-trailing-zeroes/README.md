# 172. Factorial Trailing Zeroes

## 我的思考

末尾 0 来自 `2 × 5`，且末尾出现 0 后继续乘任何数都不会改变已有末尾 0，因此可以统计每个因子的局部贡献并累加。

问题转化为统计 `n!` 中有多少个因子 2 和因子 5。

对于因子 5：

`1 × 2 × 3 × ... × n`

中所有 5 的倍数都至少贡献一个因子 5，共有 `n / 5` 个。把这一层 5 全部剥离后，问题变成统计新的数列中还剩多少个因子 5，与原问题同构，只是规模缩小为 `n / 5`。

因此不断执行：

```java
count += n / 5;
n /= 5;
```

直到 `n == 0` 即可。

由于i /= 5显然比i /= 2衰减的快，而且每一步累加答案时，i / 5 也显然小于 i / 2，所以2的数量显然严格多于5的数量

## 卡点

无。

## 关键点

不断剥离所有包含因子 5 的数中的一层 5，每轮新增 `n / 5` 个因子 5，剩余部分与原问题同构，只是规模缩小为 `n / 5`。

## 复杂度

时间复杂度：`O(log₅ n)`。

空间复杂度：`O(1)`。

## 注意

不要停留在 "`n / 5` 就是答案"。

25、125、625……分别额外贡献一个、两个、三个因子 5，因此需要不断缩小规模继续统计。

# 43. Multiply Strings

## 我的思考

采用十进制竖式乘法，枚举 `num1` 与 `num2` 的每一位，两位数字的乘积分别贡献到结果数组的 `i + j` 和 `i + j + 1` 位置。

结果使用长度为 `m + n` 的字符数组保存。每次写入某一位时，通过辅助函数立即处理可能产生的进位。全部乘积累加完成后，跳过结果数组前部的零并构造最终字符串。

## 卡点

耗时 20min。

## 关键点

长度分别为 `n`、`m` 的两个十进制整数相乘，结果长度最多为 `n + m`。

当两个数字位于各自字符串的下标 `i` 和 `j` 时，其乘积的个位贡献到 `i + j + 1`，十位贡献到 `i + j`。

本质是将每一对数字的局部乘积累加到对应的全局位置，再处理进位。

## 复杂度

时间复杂度：`O(nm)`。

空间复杂度：`O(n + m)`。

## 注意

可以先累计局部贡献，再最后统一for循环处理进位

`char[]` 在本实现中既表示字符，也承担数字位累加与进位的职责。虽然能够正确工作，但 `int[]` 的语义更直接，也更适合先累计所有局部贡献、最后统一处理进位。

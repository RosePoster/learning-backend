# 80. Remove Duplicates from Sorted Array II

## 我的思考
这题要求在有序数组中原地去重，但每个元素最多保留两次。

一开始使用 `slow / fast` 双指针，并额外维护 `has2Same`，表示当前保留区末尾的元素是否已经出现两次。这样可以避免每次都重新判断 `nums[slow] == nums[slow - 1]`。

后来发现，因为数组有序且最多保留 2 个，其实可以直接用保留区倒数第 2 个元素来判断当前元素是否还能加入。

如果当前准备写入的位置是 `slow + 1`，那么只需要比较：

`nums[fast] != nums[slow - 1]`

如果相等，说明保留区末尾已经有两个相同元素，当前元素不能再放；如果不等，说明当前元素最多只出现过一次，可以加入。

## 卡点
第一版维护了一个 boolean 状态，逻辑正确，但状态变量让代码推理成本更高。

更简洁的写法是直接利用“最多保留 2 个”的位置关系判断，而不是显式维护当前值是否已经出现两次。

## 关键点
有序数组原地去重，最多保留 `k` 个时，可以用保留区中倒数第 `k` 个元素判断当前元素是否还能加入。

本题 `k = 2`，因此判断条件可以写成：

`nums[fast] != nums[slow - 1]`

也可以用更通用的写法理解为：

`nums[fast] != nums[write - 2]`

其中 `write` 是下一个要写入的位置。

## 主流解对照
第一版的 boolean 状态解法可以通过，但不如位置判断写法简洁。

位置判断写法更容易推广到“最多保留 k 次”的问题。

## 复杂度
时间复杂度：O(n)

空间复杂度：O(1)

## 注意
这题的关键不是“是否能省掉一次比较”，而是利用有序数组的性质：如果当前元素等于保留区倒数第 2 个元素，就说明它已经保留了两次，不能继续加入。

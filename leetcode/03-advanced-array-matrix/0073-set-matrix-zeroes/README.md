# 73. Set Matrix Zeroes

## 我的思考
一开始想到用额外数组记录哪些行、哪些列出现过 0，然后再统一把这些行列置 0。

如果不限制空间，这个做法很直接：

- `rowFlag[i]` 表示第 i 行是否需要清零；
- `colFlag[j]` 表示第 j 列是否需要清零。

但题目要求常量辅助空间。最初尝试从“利用数据本身做标记”的角度思考，例如特殊值、特殊 bit、位运算等，但由于矩阵元素范围覆盖整个 int，不能依赖特殊值标记。

后来意识到，虽然不能额外开行列标记数组，但可以把这些标记数组嵌入矩阵本身：

- 用 `matrix[i][0]` 表示第 i 行是否需要清零；
- 用 `matrix[0][j]` 表示第 j 列是否需要清零。

由于第一行和第一列本身也可能含 0，需要额外用两个 boolean 记录它们原本是否需要清零。

## 卡点
卡点不是没有想到“行列标记”，而是没有想到可以把 `rowFlag[]` 和 `colFlag[]` 复用到矩阵的第一列和第一行中。

过去理解的原地标记更多是 element-level marker，比如取负数、置特殊值、置 0/1。

这题使用的是 dimension-level header marker：用一行/一列的代表位置标记整行/整列状态。

## 关键点

用第一行列来记录信息。
再用两个额外的boolean标记记录第一行列本身的信息。

## 复杂度
时间复杂度：O(n * m)

空间复杂度：O(1)

## 注意
这题的可迁移经验是：

当需要额外的标记数组时，可以思考能否把标记数组映射到原数据结构中的某些代表位置上。

例如本题中：

`rowFlag[i] -> matrix[i][0]`

`colFlag[j] -> matrix[0][j]`

这类方法不是“在元素自身上标记”，而是“用代表位标记一类元素”。

# 86. Partition List

## 我的思考
这题要求按 `x` 分区链表，并保持两部分内部相对顺序。

有两种思路：

1. 原地移动节点  
   先找到 `< x` 前缀的尾节点，然后向后扫描。遇到 `< x` 的节点，就从当前位置摘出，插入到小于区尾部。

2. 双链表收集  
   分别维护 `less` 链表和 `greaterOrEqual` 链表。遍历原链表时，小于 `x` 的节点接到 `less`，否则接到 `greaterOrEqual`，最后拼接两个链表。

第一时间想到并写出了第一种，然后想到了第二种。
第一种也是最优复杂度，但第二种语义更清晰，更适合作为最终提交。

## 卡点
无明显卡点。

## 关键点
本题本质是 stable partition。

双链表写法更直接：

- `< x` 的节点进入 less 链表；
- `>= x` 的节点进入 greaterOrEqual 链表；
- 最后拼接两条链表。

复用原链表节点时，最后需要断开 greater 链表尾部：

`greaterTail.next = null`

## 复杂度
时间复杂度：O(n)

空间复杂度：O(1)

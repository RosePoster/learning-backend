# 54. Spiral Matrix

## 我的思考
最开始按层遍历矩阵，每一层依次走上边、右边、下边、左边。

一开始只处理了完整外圈，没有单独考虑最内层退化为一行或一列的情况，因此在 3x3 矩阵中漏掉了中心元素。

随后尝试针对正方形奇数阶矩阵补中心点，但这个修复无法泛化到矩形矩阵，例如最内层可能是一整行或一整列。

最终改为在每一层中显式定义边界：

top / bottom / left / right

然后在 layerOrder 内部统一处理三种情况：只剩一行、只剩一列、完整一圈。

## 卡点
最开始进入了针对测试用例打补丁的状态，没有先抽象出“最内层退化层”的统一模型。

直接使用 n - layer - 1、m - layer - 1 写下标时，符号计算复杂，可读性和可维护性都比较差。

## 关键点
按层遍历时，每一层不一定都是完整四条边。

需要区分三种情况：

1. top == bottom：当前层只剩一行
2. left == right：当前层只剩一列
3. 否则：当前层是完整一圈

完整一圈遍历时，每条边只处理到下一个角点之前，避免角点重复加入。

## 主流解对照
另一种主流写法是维护 top / bottom / left / right 四个边界，用 while 循环逐步收缩边界。

当前写法是按 layer 分层，本质等价，但需要在 layerOrder 中处理退化层。

## 复杂度
时间复杂度：O(mn)

空间复杂度：O(1)，不计返回结果。

## 注意
测试用例可以帮助发现边界问题，但不能代替模型推导。

如果发现自己开始在外层函数里补特殊元素，通常说明内层函数的职责边界不清晰。

矩阵边界题应优先使用 top / bottom / left / right 这类语义变量，避免到处直接写 n - layer - 1、m - layer - 1。

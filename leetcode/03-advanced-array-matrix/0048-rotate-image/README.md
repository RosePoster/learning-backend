# 48. Rotate Image

## 我的思考
一开始想通过左右翻转一次、上下翻转一次来完成旋转，但写出来后发现这实际等价于旋转 180°，不是题目要求的顺时针 90°。

顺时针 90° 可以通过“先上下翻转，再沿主对角线翻转”完成。不过这个做法里两个操作的语义不同，复用同一个翻转函数的收益不高。

因此最终选择按层处理矩阵，每一层做四点轮换，直接把四个对应位置的元素顺时针移动。

## 卡点
最开始把“两个方向翻转”误认为可以得到 90° 旋转，实际得到的是 180°。

另外，四点轮换的参数较多，代码可读性一般。

## 关键点
顺时针旋转 90° 时，每一组对应位置满足：

top -> right
right -> bottom
bottom -> left
left -> top

按层遍历时，只需要遍历当前层的上边，不包括最后一个点，避免重复处理角点。

## 主流解对照
主流做法之一是：

先上下翻转矩阵，再沿主对角线翻转。

该方法代码通常更短，但四点轮换更直接体现了原地旋转过程。

## 复杂度
时间复杂度：O(n^2)

空间复杂度：O(1)

## 注意
swap 这个命名不够准确，实际执行的是四点轮换，命名为 rotateFour 会更清晰。

如果使用四点轮换，需要特别注意下标映射，最好用 layer / first / last / offset 来降低出错率。

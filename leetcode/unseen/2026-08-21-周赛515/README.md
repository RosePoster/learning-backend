# 4026. Maximum Gap

## 思考过程

这题读完后，首先观察到目标是：

> 选择一个合法的 skill 子序列，使删除掉的中间部分长度最大。

如果固定 skill 中某个位置作为分界点，那么最大间隔一定来自：

- 左侧匹配位置尽可能靠前；
- 右侧匹配位置尽可能靠后。

因此可以分别求：

- `left[i]`：匹配 `skill[0..i]` 时，`skill[i]` 能达到的最早位置；
- 从右往左扫描，找到每个字符作为右端点时的最晚位置。

最终答案就是：

> 每个切分位置对应的「右侧最晚位置 - 左侧最早位置」的最大值。

代码中第一次正向扫描记录最左匹配：

```java
left[skillidx] = i;
```

第二次反向扫描时，每匹配到一个字符，就计算当前右端点和前一个字符最早位置的距离：

```java
ans = Math.max(ans, i - left[skillidx]);
```

其中 `skillidx--` 后利用的是前一个位置的左边界。

O(n + m)

- n = skill 长度
- m = station 长度

空间复杂度：

```

```

用于保存左侧匹配位置。

## 复盘笔记

# 4022. K-th Digit

## 我的思考

耗时30min

先判断 `k` 落在哪个位数层级。

对于 `i` 位整数，共有 `9 * 10^(i - 1)` 个，每个数占 `i` 位，因此该层级一共贡献：

`i * 9 * 10^(i - 1)`

个数字。

从 `k` 中不断减去完整层级的长度，直到 `k` 落在当前 `i` 位数区间中。

接下来暂时忽略题目的逆序规则，把整个序列视为普通顺序排列。

当前区间中，每个整数占 `i` 位，因此：

`(k - 1) % i`

可以确定当前 `k` 对应整数中的第几位，记为 `digitIndex`，其中 `0` 表示最高位。

而：

`(k - 1) / i`

表示从当前位数区间的第一个整数开始，已经完整经过了多少个整数，因此可以得到当前对应的整数 `num`。

确定 `num` 和 `digitIndex` 后，即可提取目标数字。

最后单独处理题目的逆序规则。

每个逆序块只是在固定的 10 个连续整数内部改变顺序，不改变整数数量、整数位数和整个层级长度，因此它与前面的无限序列定位过程不耦合，可以最后局部修正。

对于同一块中的：

`10b, 10b + 1, ..., 10b + 9`

逆序后变为：

`10b + 9, ..., 10b`

这些数除了个位以外的所有位都完全相同，因此逆序实际上只影响个位。

如果当前目标位不是个位，则无需修正。

如果当前目标位是个位，并且当前块需要逆序，则：

`ans = 9 - ans`

即可得到真实结果。

## 卡点


## 关键点
把题目的 block 逆序与全局位置定位拆开处理。

逆序不会影响任何位数层级的长度，也不会影响除个位外的数字，因此可以先按照普通自然数序列完成定位，最后仅对满足条件的个位执行 `x -> 9 - x` 的局部修正。

## 注意
- `k` 使用 1-based indexing，因此位置计算统一使用 `k - 1`。
- `digitIndex = (k - 1) % i`，其中 `0` 表示最高位，`i - 1` 表示个位。
- 当前块是否逆序可以直接根据 `num / 10` 的奇偶性判断。
- `((num / 10) % 10) % 2 == 1` 虽然正确，但可以简化为 `(num / 10) % 2 == 1`。
- `bios` 的实际含义是当前位数层级中的整数数量，命名为 `count` 或 `rangeCount` 会更清晰。

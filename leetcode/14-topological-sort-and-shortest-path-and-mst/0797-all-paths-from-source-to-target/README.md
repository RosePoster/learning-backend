# 797. All Paths From Source to Target

## 我的思考
本题很快锁定为回溯。总耗时约 15min。

本题记录的 solution 采用：`dfs(curr)` 内部负责将当前节点加入 `path`，搜索完成后再将当前节点从 `path` 中移除。

这种写法的递归职责更完整：进入 `dfs(curr)` 时，将 `curr` 作为当前选择加入路径；如果 `curr` 是终点，则复制当前路径加入答案；否则继续递归搜索所有后继节点；函数返回前撤销当前节点。

相比常规写法，这里不需要调用方提前把当前节点加入 `path`，递归函数本身闭合了“选择-递归-撤销”的完整流程。

## 卡点
无。

## 关键点
- 当前路径用 `path` 维护，到达终点时需要复制一份加入答案，复制语法是 `ans.add(new ArrayList<Integer>(path));`.

## 复杂度
- 时间：`O(P * n)`，其中 `P` 为从源点到目标点的路径数量，复制每条路径最坏需要 `O(n)`。
- 空间：`O(n)`，不计答案空间；若计入答案，则为 `O(P * n)`。

## 注意
- 常规写法的语义是：调用 `dfs(curr)` 前，`curr` 已经在 `path` 中；这种写法的语义是：`dfs(curr)` 自己负责加入和移除 `curr`。
- 这种写法需要注意的是，找到答案也需要删除末尾节点。也就是使用if-else来统一在函数结尾移除末尾元素。

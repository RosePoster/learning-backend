## 二、学习体系评估

### 2.1 方法论设计（突出优势）

这套体系明显超出常规刷题仓库的水准，核心在于它针对的不是"题量"，而是**虚假进步**这一刷题最大风险：

- **四 Phase 分工明确**：NEW（完整流程）/ AUDIT（反虚假进步限时复盘）/ MOCK（45min 硬截止 + 自造反例 + 出声讲）/ UNSEEN（迁移训练）。尤其 MOCK 与 UNSEEN 的区分——"MOCK 测记忆稳定性，UNSEEN 测迁移能力，二者不可互替"——是多数备考者意识不到的关键区别。
- **量化触发器**：审计失败率 > 30% 整组扩审、连续 3 题无独立思路则暂停补模板。规则可执行、不依赖主观感觉。
- **review 调度有节奏**：`[r]` > `[x/r]` 优先级、每 5-7 道新题穿插 1 道、明确时间窗，避免错题堆积到末期。
- **现实主义**：春节窗口明确标记零产出；Easy 边际价值过低的题被主动删除换 UNSEEN 场次；ACM 笔试 IO 形态提前到 2027-01 演练。

### 2.2 体系层面的风险

1. **审计滞后于衰减**。旧 R1-R6（二分/前缀和/堆/滑窗/双指针）完成最早，但集中审计排在 Round 4，距今还有约 30+ 题的推进量。虽有 7 道抽审兜底，最早的记忆在到达审计点时可能已衰减 4-5 个月。建议把 R4 的抽审 7 题拆散，立即按"每周 1-2 道"穿插，而非等 R3 走完。
2. **ROADMAP 中同题多轮重复**（146 出现在 R2/R9/R18，56 在 R4/R9，329 在 R8/R10 等）。设计上是有意的（不同 Phase 不同标准），但缺少交叉引用标记，后期容易出现"这题到底过没过本轮标准"的状态混乱。建议在重复条目后注明首次出现轮次。
3. **文档债**：README.md 仍引用已废弃的 `templates/` 与 `00_legacy_archived/`（实际为 `legacy/`）；EXECUTION.md 与 ROADMAP 的 Execution Notes 内容重叠。另外执行流程写明"AC → 笔记 → git"，但本目录未发现 git 仓库（若 .git 在上级目录则忽略此条；否则版本控制这环是缺失的，断档无法追溯）。

需要警惕其反面：1334 insight 自己承认"优化复杂度已明显超过本题"。这种深挖在每轮一篇的频率下是优势，频率失控就是进度杀手。建议给单篇 insight 设硬性时间盒（如 3 小时）。

## 五、笔记与代码质量

### 5.1 笔记

两篇 insight 达到可发表水准：有反例、有论证链、有与底层系统（fast path / cache coherence / speculative execution）的迁移联想。这类材料在面试中是"讲深度"的现成素材，**建议整理成博客/知乎文章挂到简历上**，对后端岗位是强信号。

legacy 笔记覆盖不均：7/12 专题有 note.md，缺 bst-tree-dp-lca、dp-string、linked-list、monotonic-stack-and-queue、stack-queue-parsing 五个——其中 stack-queue-parsing 恰是最弱簇，**这个专题最该有总结却没有**，建议在重做 224/227/316/1249 时补写。

新区 README 质量两极：146/990/959 等有完整"我的思考 + 卡点 + 主流解对照"，但 0547/1202/1971/0705 为空文件、0173 仅 2 行。按"笔记优先级"规则简单题不写长笔记是对的，但空文件是噪音——要么删除、要么留一行"模板题，无卡点"。

### 5.2 代码

风格总体一致：标准 UF 模板、`{node, distSnapshot}` 入队、dirs 数组遍历。graph 笔记自查出的三处"风格债"（994 双队列、542/695 方向 unroll、934 多档 sentinel）结论正确——复刷时优先统一风格而非重新求解。唯一的结构性缺失是没有任何本地测试脚手架，所有验证依赖 LC 提交；对 MOCK 阶段"自造反例、不依赖 LC 测试用例 debug"的要求来说，一个最小的 main 方法模板或 JUnit 脚手架会显著提速。

## 七、总评

这不是一个刷题仓库，而是一套带反馈控制的训练系统：有单一事实来源（ROADMAP）、有防自欺机制（AUDIT/UNSEEN）、有错题闭环（R19 + 调度规则）、有元认知沉淀（insight）。设计水准高于绝大多数同阶段备考者，主要风险全部集中在**执行侧**：节奏略低于目标线、审计滞后于衰减、最弱专题恰好缺总结。若三者在 Round 3-5 期间修正，按当前质量推进，2027-02 投递前完成主线并具备一线大厂算法面强度，是现实可达的目标。

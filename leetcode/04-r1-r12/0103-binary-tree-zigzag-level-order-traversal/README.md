# 103. Binary Tree Zigzag Level Order Traversal

## 我的思考
用两个 deque 交替处理当前层和下一层，并根据遍历方向调整下一层子节点入队顺序。

## 卡点
反向遍历时，需要同步反转 left / right 的入队顺序，脑补较费力，用草稿纸画会更稳。

## 关键点
若用双 deque / 双栈做法，下一层的弹出顺序取决于当前层压入下一层的顺序，因此方向切换时，子节点入队顺序也要反转。

## 主流解对照
更稳的写法是普通 BFS：队列始终按 left -> right 入队，只在当前层结果中根据方向选择 addLast 或 addFirst，避免维护复杂的节点入队顺序。

## 复杂度
时间复杂度：O(n)  
空间复杂度：O(n)

## 注意
面试优先写普通 BFS + LinkedList 控制插入方向，代码更短，bug 面更低。

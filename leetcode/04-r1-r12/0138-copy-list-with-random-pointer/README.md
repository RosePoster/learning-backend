# 138. Copy List with Random Pointer

## 我的思考
本次复刷耗时 27min。使用 O(1) 空间三步法：

1. 在每个原节点后插入复制节点；
2. 根据 `old.random.next` 修正复制节点的 `random`；
3. 拆分原链和复制链。

## 卡点
第二轮一开始用 `copyNode` 遍历，写出了：

`copyNode = copyNode.next.next`

这里忽略了最后一个复制节点的 `next` 可能为 `null`，导致空指针异常。

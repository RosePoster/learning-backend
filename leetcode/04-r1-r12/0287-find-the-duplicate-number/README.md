# 287. Find the Duplicate Number

## 我的思考
一开始没有看清题目限制，直接写出了原地归位法：

把 `nums[i]` 放到下标 `nums[i] - 1` 的位置，如果目标位置已经有相同值，则找到重复数。

但这题要求不能修改数组，因此该做法不符合题意。

随后在提示后转向值域二分和快慢指针。值域二分没有独立想到；快慢指针虽然推出了 `a + c = kb`，但没有继续变形出 `a = kb - c`，因此没有独立推出从 `head` 和 `meeting` 同步走会在环入口相遇。

## 卡点
没有主动想到值域二分和快慢指针。

快慢指针推导卡在：

`a + c = kb`

没有继续推出：

`a = kb - c`

也就没有独立得出：从相遇点再走 `a` 步，等价于在环内走 `b - c` 步，刚好到环入口。

## 关键点
值域二分不是对下标二分，而是对值域 `[1, n]` 二分。

统计 `<= mid` 的元素个数 `cnt`：

若 `cnt > mid`，说明 `[1, mid]` 中必有重复数；否则重复数在 `[mid + 1, n]`。

快慢指针中，把数组看成链表：

`i -> nums[i]`

重复数对应环入口。

设：
- `a`：起点到环入口距离
- `b`：环长度
- `c`：环入口到相遇点距离

相遇时：

`a + c = kb`

因此：

`a = kb - c`

从相遇点再走 `a` 步，等价于走 `b - c` 步，正好回到环入口；从 head 走 `a` 步也到环入口，所以二者同步走会在环入口相遇。

## 主流解对照
本题主流解有两种：

1. 值域二分：O(nlogn)，O(1)
2. 快慢指针：O(n)，O(1)

原地归位法虽然直观，但会修改数组，不符合题目限制。

## 复杂度
值域二分：时间复杂度 O(nlogn)，空间复杂度 O(1)  
快慢指针：时间复杂度 O(n)，空间复杂度 O(1)

## 注意
这题限制：不能修改数组。

快慢指针不要只记模板，要能解释为什么从 `head` 和 `meeting` 同步走会在环入口相遇。

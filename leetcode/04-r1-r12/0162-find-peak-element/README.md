# 162. Find Peak Element

## 我的思考
一开始纠结 `left / mid / right` 三者的整体大小关系，后来意识到题目给定 `nums[-1] = nums[n] = -∞`，这是峰值存在性的兜底，不需要分析全局形态。

同时通过 `while (left + 1 < right)` 保证 `mid - 1` 和 `mid + 1` 都合法。结尾在两个候选点中返回较大者，并兜住 `n = 1` 和 `n = 2`。

## 卡点
起初试图分析 `left / mid / right` 的整体大小关系，导致思路变复杂。

## 关键点
不要分析全局形态。利用边界负无穷保证峰值存在，只需要根据局部坡度收缩区间。

## 主流解对照
主流写法通常只比较 `nums[mid]` 和 `nums[mid + 1]`：若下降，则左侧含峰值；若上升，则右侧含峰值。比三点判断更简洁。

## 复杂度
时间复杂度：O(log n)  
空间复杂度：O(1)

# 347. Top K Frequent Elements

## 我的思考
一开始自然想到统计频率后用小根堆维护前 k 个，复杂度为 O(m log k)，其中 m 是不同数字个数。

在提示“频率有限”后，意识到频率最大不超过 n，可以把 `freq` 直接作为数组下标归类。由于多个数字可能共享同一个频率，所以每个位置用 `List` 承接，而不是单个元素。

## 卡点
从“小根堆比较频率”切换到“频率作为下标直接归类”这一层抽象。

## 关键点
关键不是桶这个名字，而是：当排序依据的值域有限时，可以用“下标直达”替代比较排序。

本题中 `freq ∈ [1, n]`，因此可以用 `buckets[freq]` 存所有出现 `freq` 次的数字，再从高频向低频扫描得到答案。

## 复杂度
时间复杂度：O(n)  
空间复杂度：O(n)

## 注意
题目保证答案唯一，因此不会出现某个频率桶跨越第 k 位、导致同频元素部分入选的情况。

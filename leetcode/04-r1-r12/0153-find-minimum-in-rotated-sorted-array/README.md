# 153. Find Minimum in Rotated Sorted Array

## 我的思考
本次复刷耗时 8min。

如果当前窗口已经有序，即 `nums[right] >= nums[left]`，则最左侧即为最小值，可以直接返回。

否则答案一定在旋转点处。通过判断 `nums[mid] >= nums[left]` 识别左侧有序段：若左侧有序，则该段不含最小值，`mid` 也可以删除，令 `left = mid + 1`；否则说明 `mid` 落在右侧低值段，`mid` 可能就是最小值，不能删除，令 `right = mid`。

## 关键点
我的思路不是找 target，而是不断删除确定不含最小值的有序段。  
左侧有序时可以删掉 `mid`；右侧有序时 `mid` 可能是旋转点，不能删。

# 341. Flatten Nested List Iterator

## 我的思考
使用懒展开（Lazy Iterator）的思路。

维护一个栈，每个栈帧保存当前列表及其遍历到的位置（list + idx）。

构造函数中预取第一个整数，之后每次 `next()` 返回缓存值，并再次预取下一个整数。

遍历过程中：
- 当前列表遍历完成则弹栈。
- 遇到整数则缓存并返回。
- 遇到子列表则将其压栈，继续向下展开。

## 关键点
- 不提前展开整个嵌套结构，而是在需要时才继续展开（Lazy Traversal）。
- 栈中保存的是「当前列表 + 当前索引」而不是所有元素。
- 使用预取（prefetch）维护 `next`，使 `hasNext()` 能够直接返回结果。

## 主流解对照
主流做法也是维护一个保存 `(list, idx)` 的栈，进行懒展开遍历。

## 复杂度
- 初始化：最坏 `O(N)`（连续跳过空列表时）。
- 总时间复杂度：`O(N)`。
- 单次 `next()`：摊还 `O(1)`。
- 空间复杂度：`O(D)`，其中 `D` 为最大嵌套深度。

## 注意
- 不要在已经维护显式栈的情况下再递归调用 `getNext()`，否则极深嵌套下仍可能导致调用栈溢出。
- `State` 可以定义为 `static` 内部类，避免持有外部类引用。
- 工程实现中，`Iterator.next()` 更规范的做法是在没有下一个元素时抛出 `NoSuchElementException`，而不是依赖调用方一定先调用 `hasNext()`。

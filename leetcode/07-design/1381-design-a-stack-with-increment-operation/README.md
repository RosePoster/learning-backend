# 1381. Design a Stack With Increment Operation

耗时：14min

## 我的思考
维护两个数组：

- `stack`：保存原始栈元素。
- `inc`：保存延迟增量。

对于 `increment(k, val)`，不立即修改底部 `k` 个元素，而是将增量记录在 `inc[min(k - 1, top)]`。

弹出元素时：
- 当前元素获得自己的延迟增量。
- 将这份增量继续传递给下一层元素。
- 清空当前位置的增量，避免数组位置复用时受到影响。

## 关键点
- 延迟标记（Lazy Propagation）思想，而不是真正修改底部 `k` 个元素。
- `inc[i]` 表示一份将在元素弹出时生效、并继续向下传递的累计增量。
- 每次 `pop()` 完成一次增量下传，因此三个操作都能做到 `O(1)`。

## 主流解对照
另一种实现利用差分数组，只使用一个数组完成所有操作。

其核心思想不是让一个整数同时保存原值和增量，而是改变状态表示：存储相邻元素之间的差值，将区间加法转化为边界修改。

这说明信息没有减少，而是通过重新编码整个序列，利用元素之间的相关性降低了维护成本。

## 复杂度
- `push`：`O(1)`
- `pop`：`O(1)`
- `increment`：`O(1)`
- 空间复杂度：`O(maxSize)`

## 注意
- 差分数组方案值得学习其状态表示思想，但工程实现比双数组方案更难理解、更容易写错，面试中通常双数组实现可读性更好。

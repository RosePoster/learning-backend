# 专题 · Graph BFS / DFS

> 类型：专题总结 ｜ 来源：旧 Round 13（15 题）

## 摘要

真正的难度分水岭不是 BFS/DFS 的实现，而是隐式图建模：把题面转成 (节点, 边, 边权, 起点, 终点) 五元组。本轮 4 道隐式图题（0127 / 0752 / 0909 / 1293）耗时约等于其余 10 道网格题之和。

## 跨题主线

### 1. DFS↔BFS 反复改向的根因：DP 思维侵入图问题

0127 用 DFS 判存在、0542 用 DFS+memo 写"当前点 = 1 + min(四邻)"，表面是两种错误，本质相同——先想"答案怎么由邻居算出来"（局部递推），而非"搜索空间长什么样"（全局扩展）。0542 的失败根因：节点互相依赖，依赖项的最短距离未收敛就被提前写入；BFS 队列按距离递增扩展，不存在依赖未稳定问题。识别钩子：题目问"最短"、脑中却在写递推式 → 立即切 BFS。

### 2. visited 的类型 = 状态空间的维度

| visited 类型 | 状态空间 | 代表题 |
|---|---|---|
| boolean / 原地 sentinel | 仅位置 | 多数网格题 |
| `int[][]` 存最优代价 | 位置 + 连续代价维度 | 1293（剩余障碍数） |
| 两个 boolean 数组取交 | 位置 + "被谁可达"集合 | 0417 |

"visited 该记什么"等价于"状态空间是什么"。想往 visited 塞标量以外的东西时，实际是在给状态加一维。1293：位置相同但资源消耗不同即不同状态，同位置下消耗更少的状态支配消耗更多的。

### 3. 隐式图建模是真分水岭

- 0127：单词 = 节点，差一位 = 边，`*` 通配 pattern 建中间分组。
- 0909：编号 1~n² = 节点，掷骰 = 6 条出边，蛇/梯 = 强制 redirect。
- 1293：状态 = (i, j, 已耗障碍数)，资源维度并入节点。
- 网格题本质也是隐式图，dirs 数组即邻接表。

五元组确定后模板全部相同；后续练习价值在隐式图建模题，而非网格 BFS 模板。

### 4. 多源 / 反向 BFS 识别

"从所有 X 同时扩散" → 全部一次性入队（0542 所有 0、1162 所有陆地、0934 整座第一岛）。"每个点能否到目标区域"不好正向判断 → 从目标反向搜（0417 两边界分别反向 BFS 取交）。

### 5. 命名模式：连通分量 + 多源最短路（0934）

先 DFS/BFS 染色识别连通分量 → 整个分量作为多源 BFS 起点。所有"两区域最短距离 / 区域到边界距离"题适用；1162 是多源点天然给定的简化版。

## 模板与肌肉记忆

分层 BFS 固定顺序（0994 / 1091 曾因先 poll 后取 size 导致层边界全错）：

```java
while (!q.isEmpty()) {
    int size = q.size();          // 先固定本层大小
    for (int i = 0; i < size; i++) {
        int[] curr = q.poll();    // 再 poll
        // ...
    }
    step++;
}
```

方向数组：`int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}}`，消除四份重复边界检查；八方向同理。

BFS 与 DFS 判定方向相反：BFS 在**入队时**判合法（越界/已访问/障碍不入队）；DFS 在**进入函数后**判非法立即 return。写错的症状：队列塞进越界点，或 DFS 先递归再判越界导致越界异常。

原地修改当 visited：状态语义必须简单，最多三档（0 未访问海 / 1 未访问陆 / 2 已访问）；0934 曾用 -1/-2 多档 sentinel，调试成本高于单开 visited。

## 建图起手 5 问（最高 ROI 的 checklist）

本轮全部"低级错误"（0127 忘加 beginWord / 忘标 visited / endWord 不在表；0909 redirect 后才能判终点；1091 先 poll 后取 size）归结为同一份起手检查：

1. 起点是否在节点集合中？要不要手动加？
2. 终点是否在节点集合中？要不要先判存在？
3. 起点入队时 visited 是否同步标记？
4. 终点判定的位置：邻居枚举后？redirect 后？
5. 分层 BFS：先 `size = q.size()` 再 `poll()`。

## 其余坑

1. 复制粘贴漏改变量（0417 只改队列名没改 toPO→toAO）→ 抽公共方法 `bfs(queue, visited)`，不靠复制扩展。
2. 有强制跳转/后处理的题，终点判定必须放在跳转之后（0909）。
3. 过早启发式剪枝（0909 只保留跳转节点）→ 完整枚举合法邻居 + visited 去重几乎永远更稳。
4. 编号↔坐标映射先举例验证规律再写公式（0909）。
5. 建 pattern 必须保留"变化在哪一位"：`s.substring(0,i) + "*" + s.substring(i+1)`，缺 `*` 会把 tail/talk 归同组（0127）。
6. 写码前先抽框架：需要几个状态数组、几次 BFS、哪些可抽公共方法（0417）。

## 面试表述

无权图最短路 → BFS，正确性来自队列按距离递增扩展的不变量；节点非显式时说明 X 映射为节点、Y 映射为边（implicit graph）；正向不好判断时从目标反向搜；visited 不一定是 boolean，存在资源/代价维度时记录最优代价才是正确剪枝。

## 复刷优先级

**B. 回收风格债**（重写统一到现行模板）：0994 双队列改 `size=q.size()` 外层循环；0542/0695 四方向 unroll 改 dirs 数组；0934 改 0/1/2 三档标记并显式记"连通分量+多源最短路"模式。
**C. 填补盲区**（本轮未出现的模式）：双向 BFS 重写 0127/0752；1293 改写为 0-1 BFS / Dijkstra；1091/1293/1926 加曼哈顿启发式（A*）。
**D.** 任何 BFS/建图题开写前过一遍起手 5 问。

# 1319. 连通网络的操作次数

按题目语义直接建模：统计当前网络中多出来的线缆数量，再统计连接所有连通分量需要多少线缆，最后判断多余线缆是否足够。

一个没第一时间想到的小优化是：可以先判断 connections.length 是否小于 n - 1。因为 n 个节点连成一个连通图至少需要 n - 1 条边，如果总线缆数量不够，可以直接返回 -1。

主流做法是先用 connections.length < n - 1 判断总线缆数量是否足够，再用 DFS/BFS 或 Union-Find 统计连通分量数量，答案为 components - 1。本解法与主流 Union-Find 解法等价，只是显式统计了冗余线缆，语义更直接；未第一时间使用总边数的提前判断

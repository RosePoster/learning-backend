# 1489. 找到最小生成树里的关键边和伪关键边

## 我的思考

本题可以从 Kruskal 的视角出发。由于最小生成树按边权从小到大选择边，因此可以先按权值排序，并按相同权值分批处理。

在每一批同权边中，上一批处理结束后的并查集状态可以视为若干已经确定的连通分量。当前批次的边只需要考虑连接不同连通分量的边；如果一条边的两个端点在上一批状态中已经属于同一个连通分量，则它不可能出现在任何最小生成树中，可以直接忽略。

对于当前同权边，将上一批并查集中的连通分量压缩为超级节点，把当前批次中连接不同超级节点的边建成一张临时无向图。此时问题转化为：在这张由同权边构成的临时图中，哪些边是不可替代的，哪些边可以被同权路径替代。

如果某条边是临时图中的桥，说明删除它会使对应的两个超级节点无法在当前权值下连通，因此该边是关键边。  
如果某条边不是桥，说明它位于某个环中，可以被同权边替代，因此该边是伪关键边。

每一批边分类完成后，再将这一批中所有连接不同旧连通分量的边加入全局并查集，进入下一批权值处理。

## 卡点

一开始尝试仅用并查集判断当前批次中的环和环上所有边，但并查集只能维护连通性，不能保留路径信息，也不能直接找出环上的所有边。

本题真正需要判断的是当前同权边组成的临时图中哪些边是桥，哪些边位于环中。因此需要在批次内建图，并使用 DFS / Tarjan 求桥，而不是继续给并查集外挂复杂状态。

## 关键点

1. 按权值分批处理，保证当前批次内部的边权完全相同，才存在“可替代性”。

2. 每批处理前的并查集状态表示更小权值边已经确定形成的连通分量。

3. 当前批次中，如果一条边两端在旧并查集中已经连通，则该边永远不可能进入任何 MST，直接丢弃。

4. 当前批次中，连接不同旧连通分量的边，需要把旧连通分量压缩成超级节点后建图。

5. 在当前批次的临时图中：
   - 桥边：删除后会破坏当前权值下的必要连通，因此是关键边。
   - 非桥边：处在环中，可以被同权边替代，因此是伪关键边。

6. 临时图可能是多重图，Tarjan 求桥时不能只用父节点跳过反向边，而应该用 parentEdgeId 跳过父边，否则会误判重边。

7. 每批分类完成后，才能把当前批次的边加入全局并查集。不能边分类边更新全局并查集，否则会破坏“同权边同时竞争”的语义。

## 主流解对照

- 主流做法通常是先求原始 MST 权值。然后对每条边分别执行两次 Kruskal：一次禁用该边，若 MST 权值变大或无法连通，则该边是关键边；一次强制选择该边，若仍能得到原始 MST 权值，则该边是伪关键边。
- 我解法与主流解的差异：我解法是更优的分组建模做法。按权值分批，将旧连通分量压缩成超级节点，在当前同权边组成的临时图上用 Tarjan 求桥，从而一次性分类当前批次的关键边和伪关键边。主流解更直接、实现更简单，但复杂度更高。

## 复杂度

- 时间：排序为 O(m log m)。每条边只会在其所属权值批次中参与一次建图和 DFS，所有批次合计为 O(m + n)。并查集操作近似为 O(m α(n))。总时间复杂度为 O(m log m + m α(n) + n)，通常可写为 O(m log m + m α(n))。
- 空间：临时图、Tarjan 数组、并查集数组等空间为 O(n + m)。

## 注意

1. 本题中“关键边”和“伪关键边”的判断必须基于 MST 语义，而不是普通图中的边分类。
2. 并查集适合判断两个点是否连通，但不适合回答“哪些边在环上”“哪些边是桥”这类结构性问题。
3. 如果采用分批 + Tarjan 解法，当前批次的图节点应该是上一批并查集中的 root，而不是原始节点。
4. 对于两端已经在旧并查集中连通的边，不能加入临时图，也不能加入答案。它既不是关键边，也不是伪关键边。
5. Tarjan 求桥时，重边是重点坑。应通过边编号 parentEdgeId 跳过父边，而不是通过父节点跳过。
6. 面试中更稳妥的优先方案是枚举每条边做“禁用/强制选择”的 Kruskal 判定，因为本题数据范围较小，实现简单且容易解释。分批 + Tarjan 是更优但实现复杂度更高的进阶解法。
